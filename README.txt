MATERIAL DE PIANO — MUSICALA
Canción: Aunque haya pruebas
Artista: Felipe Garibo

Archivos:
- index.html: página principal
- styles.css: estilos y paleta Musicala
- script.js: reproducción de notas e interacción del teclado
- assets/logo-musicala.png: logo horizontal suministrado

Uso:
1. Descomprime la carpeta.
2. Abre index.html en Chrome, Edge, Firefox o Safari.
3. Para publicarla, sube todos los archivos conservando la misma estructura.
